What this is

Protocol, coordinator, community.

Mostro

The protocol

Open-source peer-to-peer Bitcoin trading over Nostr, using Lightning hold invoices to coordinate trades.

Mostro Venezuela

The community

A European community for users who want to learn, trade, help each other and build reputation through real P2P use.

Coordinator

The access point

Compatible Mostro clients connect using the coordinator's Nostr public key and public relays.

Clients

Mostro Mobile · Android

Add MostroEuropa as a custom node

Open Settings in Mostro Mobile.

Scroll to the Mostro section and tap the current node.

Choose Add Custom Node.

Paste the MostroEuropa npub shown above. The name field is optional.

Confirm and select the new custom node.

Zapstore ↗ GitHub ↗
MostriX · Terminal UI

Change the coordinator from Settings

Install and launch MostriX.

Open Settings and select Change Mostro Pubkey.

Paste the MostroEuropa npub or hex public key.

Open Mostro Info and verify the coordinator information.

export MOSTRO_PUBKEY="npub1mg36x8t42usn32upfxg35ppzfqf2xj76v7w2hf7trqj0ma79jtkqrj3q9m"

Store any mnemonic or recovery phrase safely before using the client for active trades.
